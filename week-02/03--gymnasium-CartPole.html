Let’s learn the Gymnasium env: CartPole-v1

  • Full documentation in this link
  • It’s a classic control environment to test your Reinforcement Learning knowledge.
  • A pole is attached by an un-actuated joint to a cart, which moves along a frictionless track.
  • The pendulum is placed upright on the cart and the goal is to balance the pole by applying forces in the left and right direction on the cart.

A thing or two about the render_modes

  • In Gymnasium, the render_mode parameter must be specified when initializing the environment via gym.make(), fixing the rendering behavior for the lifetime of that environment instance.
  • Common Render Modes
    • “human”: Renders the environment to a visible window on your screen so you can watch the agent.
    • “rgb_array”: Returns an numpy array representing an RGB image of the rendered frame, useful for video recording or processing.
    • “ansi”: Returns a string (str) or terminal-based ANSI escape sequence representation of the environment.
    • None: Disables rendering entirely (this is the default behavior if the parameter is omitted).

Action Space of CartPole-v1

  • The action is a ndarray with shape (1,) which can take values {0, 1} indicating the direction of the fixed force the cart is pushed with.
    • 0: Push cart to the left
    • 1: Push cart to the right

Let’s query its action space

print(f'env.action_space = {env.action_space}')
env.action_space = Discrete(2)

Observation Space of CartPole-v1

  • The observation is a ndarray with shape (4,) with the values corresponding to the following positions and velocities:
Num Observation Min Max
0 Cart Position -4.8 4.8
1 Cart Velocity \(-\infty\) \(+\infty\)
2 Pole Angle \({-0.418}^c = -{24}^o\) \(+{0.418}^c={24}^o\)
3 Pole Angular Velocity \(-\infty\) \(+\infty\)

Let’s query its observation space

print(f'env.observation_space = {env.observation_space}')
env.observation_space = Box([-4.8               -inf -0.41887903        -inf], [4.8               inf 0.41887903        inf], (4,), float32)

Rewards in CartPole-v1

  • Since the goal is to keep the pole upright for as long as possible, by default, a reward of +1 is given for every step taken, including the termination step.
  • The default reward threshold is 500.

Start state of env CartPole-v1

  • All observations are assigned a uniformly random value in (-0.05, 0.05)

End state of env CartPole-v1

  • The episode ends if any one of the following occurs:
    • Termination: Pole Angle is greater than \(\pm {12}^o\)
    • Termination: Cart Position is greater than \(\pm 2.4\) (center of the cart reaches the edge of the display)
    • Truncation: Episode length is greater than 500

import gymnasium as gym
from tqdm import tqdm

#number of timesteps
n = 500

#Since we pass render_mode="human", 
#   you should see a window pop up rendering the environment.
env = gym.make("CartPole-v1", render_mode="human")

env.action_space.seed(42)

observation, info = env.reset(seed=42)

for _ in tqdm(range(n)):
    #Pick a random action from the action spaces
    action = env.action_space.sample()

    #Act the action and then observe
    observation, reward, terminated, truncated, info = env.step(action)
    
    #Check for terminated or truncated.
    if terminated or truncated:
        observation, info = env.reset()
        #break

env.close()

# Filename: cartpole-v1-with-gif.py
# The imports
import gymnasium as gym
import math
import imageio.v2 as imageio
import os
import numpy as np
from tqdm import tqdm
import matplotlib.pyplot as plt
from joblib import load, dump

#number of timesteps
n = 500

#The CartPole-v1 environment with a random agent
# Goal is to control the cart (i.e., platform) with a pole attached by 
#      its bottom prt.
# Trick: The pole tends to fall right or left and you would need to 
#      balance it  by moving the cart to the right or left on every step.
render_mode = 'rgb_array' #or, 'human'
env = gym.make("CartPole-v1", render_mode=render_mode)
observation, info = env.reset(seed=42)

# Initialize empty buffer for the images that will be stiched to a gif
# Create a temp directory
filenames = []
try:
    os.mkdir("./videos")
    os.mkdir("./videos/temp")
except:
    pass

#Here below, we created the environment and initialized few variables.
total_reward = 0.0
total_steps = 0

episode = 1
step = 0
for i in tqdm(range(n)):
    # Plot the previous state and save it as an image that 
    # will be later patched together as a .gif object
    img = plt.imshow(env.render())

    plt.title("Episode: {}, Step: {}".format(episode,step))
    plt.axis('off')
    plt.savefig("./videos/temp/{}.png".format(i))
    plt.close()
    filenames.append("./videos/temp/{}.png".format(i))

    #Pick a random action from the action space
    action = env.action_space.sample()
    
    #Act on the picked action
    observation, reward, terminated, truncated, info = env.step(action)

    step += 1

    total_reward += reward
    total_steps += 1

    if terminated:
        episode += 1
        step = 0
        observation, info = env.reset()
        #break

print(f'Episode terminated in {total_steps} steps')
print(f'Total rewards accumulated = {total_reward}')


# Now, stitch the images together to produce a .gif
with imageio.get_writer('./videos/CartPole-v1-random.gif', mode='I') as writer:
    for filename in filenames:
        image = imageio.imread(filename)
        writer.append_data(image)

# Cleanup/delete the temporary images for the next run
for f in filenames:
    os.remove(f)


env.close()

How our random CartPole-v1 agent did?

  • On average, this random agent takes 12 to 15 steps before the pole falls and the episode ends
  • Most of the environments in Gymnasium have a reward boundary, which is the average reward that the agent should gain during 100 consecutive eposides to solve the environment.
  • For cartpole, the boundary is 500. That means, on average, the agent must hold the stick for 500 time steps or longer.
  • So, our random agent’s performance is extremely poor.
